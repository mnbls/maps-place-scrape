maps-place-scrape

Ambil daftar tempat dari Google Maps untuk satu wilayah, simpan sebagai file Excel siap olah.

Unduh ZIP Lihat kode di GitHub

Cara pakai (Windows)

  1. Pasang Node.js versi LTS. Pastikan Chrome atau Edge ada di komputer.
  2. Unduh ZIP di atas, lalu ekstrak.
  3. Klik dua kali start.bat. Pertama kali ia memasang kebutuhan sendiri (1-2 menit), lalu browser terbuka di http://localhost:3737.
  4. Isi jenis tempat dan wilayah (satu kecamatan per pencarian), lalu klik Cari.
  5. Chrome terbuka sendiri dan membaca Google Maps. Jangan ditutup sampai selesai (sekitar 10-30 menit per kecamatan).
  6. Unduh Excel dari halaman itu. Hasil juga tersimpan di folder hasil/.

Apa yang didapat

Satu file Excel dengan tiga sheet: Data Mentah (teks asli dari Maps), Data Bersih (angka siap hitung), dan Keterangan (tanggal, kata kunci, arti kolom).

Nama dan kategoriNama tempat di Maps dan jenisnya (mis. Kafe, Kedai Kopi)
RatingRating bintang dan jumlah ulasan, sebagai angka
KoordinatLintang dan bujur (lat, lng)
Jam operasionalJam buka dan tutup tiap hari, penanda buka 24 jam
Wilayah dan sumberWilayah yang dicari dan kata kunci yang menemukannya

Mengetik coffee atau kopi otomatis mencari "coffee shop", "kafe", dan "kedai kopi", lalu menggabungkan hasilnya tanpa duplikat.

Batasan

  • Rentang harga dan "bisa makan di tempat" biasanya kosong. Maps menyembunyikannya dari Chrome otomatis. Kolomnya tetap ada.
  • Hasil adalah tempat yang tampil di Maps untuk pencarian itu, bukan jaminan seluruh tempat di wilayah. Satu pencarian dibatasi sekitar 60-120 hasil.
  • Scraping langsung melanggar ketentuan layanan Google Maps. Pakai dengan risiko sendiri, dan sebutkan hal ini bila datanya dipakai di laporan.
  • Google bisa meminta verifikasi (CAPTCHA). Selesaikan di jendela Chrome yang terbuka.

Kenapa tidak bisa dipakai langsung di halaman ini?

Halaman ini hanya panduan. Aplikasinya butuh server dan Chrome yang terbuka di komputer, yang tidak tersedia di GitHub Pages. Karena itu aplikasinya dijalankan di komputer sendiri.
